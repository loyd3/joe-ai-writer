# 端口配置说明

## 两种运行环境

| 环境 | 前端 | 后端 | 数据库 |
|------|------|------|--------|
| 本地开发 | http://localhost:5173 | http://localhost:8000 | 本机 MySQL（见 `.env` 的 `DATABASE_URL`） |
| Docker | http://localhost:8080 | http://localhost:9000 | 容器内 `mysql:3306`（见下方） |

## 本地开发

```bash
cp .env.example .env
python init_db.py
python start.py
```

## Docker

```powershell
copy .env.docker .env
.\deploy.bat
```

详细说明见根目录 [DOCKER_DEPLOY.md](../DOCKER_DEPLOY.md)。

### 容器内数据库连接（后端使用）

```
mysql+pymysql://joewriter:joewriter123@mysql:3306/joe_writer?charset=utf8mb4
```

主机名必须是 **`mysql`**（Docker Compose 服务名），不是 `localhost`。

## 环境变量

- 本地开发：`.env.example` → `.env`
- Docker：`.env.docker` → `.env`（`MYSQL_*` + AI Key）

## 健康检查

```bash
# 本地
curl http://localhost:8000/health

# Docker
curl http://localhost:9000/health
```
