# 端口配置说明

## 概述

本项目支持两种运行环境：
- **本地开发环境**：用于开发调试
- **Docker 生产环境**：用于部署上线

## 端口分配

### 本地开发环境

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 (Vite) | 5173 | 开发服务器 |
| 后端 (FastAPI) | 8000 | API 服务 |

**启动方式：**
```bash
# 启动后端
cd backend
python start.py

# 启动前端
cd frontend
npm run dev
```

### Docker 环境

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 (Nginx) | 80 | Web 服务 |
| 后端 (FastAPI) | 9000 | API 服务 |
| MySQL | 3306 | 数据库服务 |

**启动方式：**
```bash
docker-compose up -d
```

## 环境变量配置

### 本地开发 (.env)

```bash
# 后端配置
DATABASE_URL=mysql+pymysql://root:password@localhost:3306/aiwriter?charset=utf8mb4
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=your-key
```

### Docker 环境 (.env.docker)

```bash
# 数据库配置
MYSQL_ROOT_PASSWORD=rootpassword
MYSQL_DATABASE=joe_writer
MYSQL_USER=joewriter
MYSQL_PASSWORD=joewriter123

# AI 配置
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=your-key
```

## API 地址配置

前端会根据运行环境自动选择正确的后端地址：

- **开发环境** (`npm run dev`)：`http://localhost:8000`
- **生产环境** (`npm run build` + Nginx)：`http://localhost:9000`

可以通过设置 `VITE_API_URL` 环境变量覆盖默认配置：

```bash
# .env.local
VITE_API_URL=http://your-custom-domain.com
```

## 常见问题

### 1. 连接被拒绝 (ERR_CONNECTION_REFUSED)

**原因**：后端服务未启动

**解决**：
- 本地开发：确保 `python start.py` 已在 8000 端口启动
- Docker 环境：确保 `docker-compose up -d` 已执行

### 2. 连接超时 (ERR_CONNECTION_TIMED_OUT)

**原因**：防火墙或网络配置问题

**解决**：
- 检查后端服务是否在正确的端口运行
- 确认 Docker 网络配置正确

### 3. 端口已被占用

**解决**：
- 修改 `backend/start.py` 中的端口配置
- 或停止占用端口的进程

```bash
# Docker 环境
curl http://localhost:9000/health
```

### 检查前端是否运行

```bash
# 本地开发

# Docker 环境
```
